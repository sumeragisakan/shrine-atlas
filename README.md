# 神祇地理志 · Shrine Atlas

日本47个都道府县的神社资料研究目录。网页按地区加载；JSON、SQLite数据库、来源范围报告和离线页面分别保存。

当前版本 **v0.5**。整理进度和实际条数见 [全国进度表](docs/NATIONAL_PROGRESS.md) 与 `data/catalog.json`，每完成一个新增地区提交一次独立commit。鸟取县原有824条记录和首批12条研究内容保留。

**这里统计的是来源记录，不等于独立、现今实存神社的数量。** 当地机构公开名录与神社史研究会检索资料分别标记；后者包含平成5年（1993）调查和合并前地址。同一地区只有唯一同名同址的记录才自动对应，其他可能重复条目保留待核。未取得的祭神、现址和坐标不推测。机构目录公开不等于所有字段均完成现况确认。

## 下载与离线查看

1. 点击 **Code → Download ZIP**，解压整个下载包。
2. 打开 [offline/japan-shrine-atlas.html](offline/japan-shrine-atlas.html)，选择地区。
3. 也可以直接打开 `offline/prefectures/` 中某一地区的HTML；鸟取县保留 [offline/tottori-shrine-atlas.html](offline/tottori-shrine-atlas.html)。

地区离线页内嵌本地区资料、地图和脚本，使用现代浏览器即可离线阅读。资料载荷采用无损gzip压缩，由浏览器的 `DecompressionStream` 解码。切换地区会经过全国离线目录，请保留文件夹结构；单独下载一个地区HTML仍能阅读该地区。外部出处需联网。

## 如何浏览

- 在全国地图或侧栏选择都道府县，页面只加载该地区资料。
- 在“探索入口”按来源所在地、祭神原文、旧社格浏览；旧地址可能包含旧市町村名。
- 地区概览按已定位记录显示地域入口。地区很多时只显示部分入口；全部地域均可在探索入口浏览。没有可核实点位的地区仍可按地址目录浏览。
- 点击地点聚合数字，先预览名称、地址和祭神，再选择放大或浏览整组。
- 移动地图后点击“浏览当前地图范围”，侧栏才更新。未定位记录不会进入地图范围结果；取消范围条件即可重新查看。
- 资料状态可选“机构资料”“仅历史待核条目”“祭神暂缺”“未定位”“待核对”。历史祭神表和地址有醒目标记。
- 来源的主配标记和神名写法分别保留，分类数量按来源记录去重，不自动统一为神格实体。

## 资料分离版

在仓库目录运行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8000/`。Windows也可以使用 `py`。直接双击根目录 `index.html` 通常会遇到本地JSON读取限制，应使用服务器或离线目录。

## 数据与数据库

| 路径 | 内容 |
| --- | --- |
| `data/catalog.json` | 47地区索引、加载路径、收录统计和状态 |
| `data/shrines/tottori/` | 原有鸟取县资料 |
| `data/shrines/NN-slug/agency-*.json` | 新地区的机构公开字段及逐项出处 |
| `data/shrines/NN-slug/history-*.json` | 尚未可靠对应的研究会条目，明确待核 |
| `data/coverage/NN-slug.json` | 来源范围、原始条数、对应规则、失败项、坐标隔离及疑似重复 |
| `docs/prefectures/` | 各地区可阅读的范围报告 |
| `database/catalog.sqlite` | 保留鸟取县的SQLite数据库 |
| `database/prefectures/NN-slug.sqlite.gz` | 新地区经过完整性验证的SQLite数据库，无损gzip封装 |
| `offline/` | 全国离线目录与每地区独立快照 |
| `scripts/` | 可复现采集、保守导入、验证及构建 |

新地区SQLite先解开一层gzip即可用SQLite客户端查询。也可以运行构建脚本重新生成；网页读取JSON，不需要数据库服务器。JSON保持文本格式，便于查看来源和修订；图片／3D模型仍采用独立文件及媒体元数据。

```bash
# 重建已收录地区、各地区数据库和离线快照
python scripts/build.py

# 只重建指定地区，并更新全国索引
python scripts/build.py --prefecture 1

# 验证地图与探索规则
node --test tests/explore-core.test.js
python -m unittest discover -s tests -p 'test_*.py'
```

构建仅使用Python标准库；SQLite需3.37以上版本。测试检查来源引用、坐标状态、地域统计、历史／机构字段分离、双地点去重及SQLite外键／完整性。

## 来源与研究边界

全国基线来自皇學館大学相关研究部会、神社史研究会与各县神社庁协作制作的 [新全国神社検索](https://jinja-net.jp/jinja-all/)。其公开说明包含历史调查和旧表记地址；不把它自动解释为现况。每条研究会记录指向公开结果提供的详情入口，检索POST参数及采集方式一并保存；不是声称所有详情均逐页复核。

当地机构资料按各自实际公开范围整理。有的提供完整名录，有的只是本务神社或精选介绍；有的详情无法访问。完整遍历一个公开目录，不等于穷尽当地所有小祠、境内末社或未列名设施。各地区报告分别说明范围、版本和缺失。

只采用来源实际公布的神社点位。地址检索、地图视窗中心或街景相机位置不转为神社坐标；县界外点保留原值但隔离不绘制。底图是国土地理院“地球地図日本”加工的旧版轮廓，不是最新行政界或导航成果。

详细规则见 [全国资料方法](docs/NATIONAL_METHOD.md)、[数据模型](docs/DATA_MODEL.md) 和 [来源及权利](docs/SOURCES_AND_RIGHTS.md)。原始网页、全文由绪、官网照片、地图密钥和个人神职联络资料不提交。公开仓库不表示第三方数据、文字、照片或模型已被重新授予统一许可。
